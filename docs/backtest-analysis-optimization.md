# 백테스트 분석 및 전략 최적화 개발 단위

## 목표와 범위

KODEX 200 단기 스윙 전략의 진입 규칙은 기준 전략으로 고정한다. 실험으로 변경할 값은 ATR 익절 배수, ATR 손절 배수, 최대 보유 거래일 세 가지뿐이다. 수익률이 가장 높은 조합을 자동 적용하지 않으며, 현재 단계에서는 거래 결과를 분석하고 비교할 근거를 만든다.

## 기준 전략: 고정 진입 규칙

| 항목 | 고정값 |
| --- | ---: |
| 장기 SMA 기간 | 120 거래일 |
| 단기 SMA 기간 | 5 거래일 |
| ATR 계산 기간 | 14 거래일 |
| 장기 SMA 기울기 비교 기간 | 5 거래일 |
| 장기 SMA 최소 이격도 | 1% |
| 매수 밴드 | 0.5 ATR |
| 진입 체결 확인 | 기존 5분봉 체결 규칙 |

## 실험 청산 규칙

| 항목 | 기본값 | 실험 후보 |
| --- | ---: | --- |
| 익절 ATR 배수 | 1.5 | 1.0 / 1.5 / 2.0 |
| 손절 ATR 배수 | 1.0 | 0.8 / 1.0 / 1.2 |
| 최대 보유 거래일 | 5 | 3 / 5 / 7 |

단일 변수 실험은 익절 ATR 배수 세 값부터 시작한다. 이후 익절·손절의 9개 조합, 마지막으로 최대 보유 기간까지 포함한 27개 조합으로 확장한다.

## 개발 단위

1. **기준 전략 고정** — 진입 규칙과 청산 실험 규칙을 분리하고, 화면에서도 청산 세 값만 수정 가능하게 한다.
2. **거래 단위 결과** — 매수·매도 체결을 완료 거래로 묶어 진입·청산·손익·청산 사유를 기록한다.
3. **분석 지표** — CAGR, 청산 사유별 손익, MFE/MAE, 연속 손실 등 거래 분석값을 계산한다.
4. **자산 곡선** — 현금, 포지션 평가액, 총자산, 평가손익 기준 MDD를 시점별로 기록한다.
5. **SQLite와 CSV 출력** — SQLite를 원본으로 저장하고 요약·거래·자산 곡선 CSV를 내보낸다.
6. **제한적 청산 파라미터 실험** — 동일 데이터·비용·체결 규칙 아래에서 3개, 9개, 27개 조합을 비교한다.

- 완료: CAGR·승률·Profit Factor·청산 사유별·월별 성과, 보유기간·고정기간 MFE/MAE, 청산 후 가격 움직임
- 완료: 제공된 KODEX 200 일봉과 5분봉(26년) 샘플을 사용하는 분석 회귀 테스트
- 완료: 5분봉 종가 시가평가 자산곡선, 실제 MDD, SQLite 원본 저장·조회, 자산곡선 CSV 및 화면 요약 연결

## 검증 원칙

- 각 실행에는 전략 버전, 기준 전략, 청산 파라미터, 데이터 기간, 시작 자금, 투자 비중과 비용 조건을 기록한다.
- 동일한 진입 규칙에서는 청산 파라미터만 달라도 진입 신호와 진입 체결 조건은 변하지 않아야 한다.
- 5분봉 OHLC만으로 봉 내부 가격 순서는 알 수 없으므로, 익절·손절 동시 도달은 현재처럼 손절 우선으로 처리한다.
- 약 1년의 데이터는 초기 비교용이다. 장기 안정성 판단과 Walk-Forward 검증은 데이터 확장 이후에 한다.

- 고정 진입 조건(SMA 120/5, ATR 14, SMA 기울기 5일, SMA 이격 1%, 매수 밴드 0.5 ATR, 기존 5분봉 확인)은 모든 후보에 공통 적용한다.
- 수동 실험 범위는 익절 3개, 익절·손절 9개, 익절·손절·최대 보유 기간 27개다.
- 후보별 실행 결과는 독립 백테스트 실행 ID와 실험 ID로 SQLite에 저장하며, `backtest_parameter_experiment_summary.csv`로 내보낸다.
